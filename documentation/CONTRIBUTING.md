# Contributing
Make a fork:
- **Step 1**: Fork the repository on GitHub.
- **Step 2**: `git clone https://github.com/{YOUR-USERNAME}/magimals-games`
- **Step 3**: Do some commits, make changes.
- **Step 4**: Make a PR.
- **Step 5**: I will either decline, accept, or tell you to do more.
- **Step 6**: Huh? What comes then? I don't know. I'll do something with the changes.
